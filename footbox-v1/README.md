# Footbox V1

Base Next.js + Supabase pour une V1 de Footbox.

## Contenu
- Auth Supabase
- Pages matchs
- Pages joueurs
- Notation /5
- Commentaires
- Classements
- Seed de 20 matchs iconiques
- Design vert/noir

## Installation
```bash
npm install
cp .env.example .env.local
npm run dev
```

## À faire ensuite
- Créer le projet Supabase
- Coller `supabase/schema.sql`
- Coller `supabase/seed.sql`
- Renseigner `.env.local`
- Lancer les imports si besoin
